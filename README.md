# Durian Executor
Durian Executor is a rayfield executor but with custom cmds like durian.loadurl() and im gonna show u all the cmds Durian Executor has right now

WARNING: DURIAN EXECUTOR IS STILL IN BETA! EXPECT BUGS AND MISSING FEATURES

# 1. Durian:loadurl()
so this will load a script from a raw link like loadstring(game:HttpGet(""))()

example: Durian:loadurl(https://url.com)

# 2. Durian:fetchurl()
so this will fetch texts from a raw link like game:HttpGet("")

example: Durian:fetchurl(https://url.com)

# 3. Durian:copy()
this will copy a text

example: Durian:copy(Hello World!)
